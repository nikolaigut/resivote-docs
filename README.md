# ResiVote Docs

Dokumentationsseite für ResiVote, aufgebaut mit [Astro Starlight](https://starlight.astro.build).

## Inhalt bearbeiten

Dokumentationsseiten befinden sich unter `src/content/docs/`. Neue `.md` oder `.mdx`-Dateien werden automatisch als Routen angelegt.

## Lokale Entwicklung

```bash
npm install
npm run dev
```

Der Entwicklungsserver läuft unter `http://localhost:4321`.

## Build

```bash
npm run build
```

Das statische Ergebnis liegt im `dist/`-Verzeichnis.
